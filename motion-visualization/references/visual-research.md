## 공통 원칙 → 모션시각화 반영

| 원칙 | 엔진 반영 |
|---|---|
| 한 번에 한 곳만 강조(딤 30~50% + 테두리·화살표 하나) | build `focus`, focus `box`, doc `row`, 노랑 말풍선 |
| 관계를 하나씩 쌓고 지우지 않음 | build 비트 누적, 선은 그려지듯 등장 |
| 같은 예시로 전후 비교, 차이만 색 | compare `*차이`, 같은 배치 유지 |
| 전체 → 부분 줌, 1.2초 이상 유지 | focus `zoom`, 자막 길이 기반 유지 시간 |
| 챕터 카드 + 진행 표시 | chapter 장면, 상단 진행 막대·로드맵 |
| 주장 뒤 실제 화면으로 증명 | doc / focus 장면을 구조 설명 뒤에 |
| 하단 흰 자막 한 줄(검정 둥근 상자), 강조어 노랑 | 자막 스타일, `**강조**` |
