# 실수 메모

- **긴 줄표(—) 쓰지 않기.** build.py가 경고한다. 쉼표·마침표·가운뎃점(·)으로 바꾼다.
- **template.html을 읽거나 고치지 않기.** 크고 토큰이 많이 든다. 모양을 바꾸려면 theme·accent·labels·블록 선택으로 해결한다. 새 블록이 꼭 필요할 때만 템플릿의 `B.<이름>` 함수와 CSS를 추가하고 content-format.md 표에 한 줄 더한다.
- **content.json 전체를 채팅에 다시 출력하지 않기.** 고칠 곳만 부분 수정하고 다시 build한다.
- **화면 확인은 check.py 한 번 + 캡처 2장.** 문제가 있을 때만 `--full` 전체 캡처를 본다. 브라우저로 섹션마다 캡처를 반복하지 않는다.
- **check.py가 SKIP이면** "화면 미확인"이라고 보고한다. 정적 점검만으로 화면 완료라고 하지 않는다.
- **원문 예시와 새 아이디어 구분.** cases의 `verified`로 라벨을 다르게 한다.
- **재구성 화면은 진짜 캡처처럼 보이지 않게** caption에 "다시 그린 화면"이라고 쓴다.
- **명령어 안내:** Windows PowerShell은 `&&` 대신 `;`. 사용자 계정 자리는 `<내계정>`처럼 바꿔 쓰게 한다.
- **실제 계정·주소·개인정보**는 본문 예시에서 빼고 출처(ledger)에만 둔다.
- **글꼴은 인터넷에서 불러온다.** 오프라인에서는 기본 글꼴로 보인다는 점을 보고에 남긴다.
